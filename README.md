# MI - PENdroid döntő 🏆🎮

> Plants vs Zombies stílusú játék - PenDroid verseny döntő feladata

## 🎯 Projekt célja

Ez a projekt a [PenDroid 2025 döntő](https://pendroid.uni-pannon.hu/verseny/hirek?view=article&id=219:veget-ert-a-pendroid-2025-os-dontoje&catid=48) keretében készült, ahol a feladat egy AI vs Ember koncepciót megvalósító játék volt. Egy Plants vs Zombies stílusú tower defense játékot fejlesztettünk Unity Engine segítségével.

## 🏆 Eredmény

**3. helyezés** - [PenDroid 2025 döntő](https://pendroid.uni-pannon.hu/verseny/hirek?view=article&id=219:veget-ert-a-pendroid-2025-os-dontoje&catid=48)

## ✨ Funkciók

- 🤖 **AI vs Ember** - *"Mesterséges intelligencia"* elleni játékmenet
- 🌱 **Tower Defense mechanika** - Plants vs Zombies stílusú védekezés
- 🎨 **Felhasználói interfész** - Egyedi UI design (gydoma által)
- 🎮 **Unity Engine** - Professzionális játékmotor használata
- ⚔️ **Stratégiai játékmenet** - Taktikai döntések és erőforrás-gazdálkodás

## 🛠️ Technológiák

- **Unity** - Game Engine
- **C#** - Programozási nyelv

## 💭 Fejlesztési folyamat

A projekt során a hajrában erősen küzdöttünk, így nem sikerült teljesen befejeznünk a játékot. Ennek ellenére a csapat kemény munkájának köszönhetően **3. helyezést** értünk el a versenyen.
